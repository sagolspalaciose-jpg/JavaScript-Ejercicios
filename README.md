# Ejercicios de clase

Repositorio con ejercicios, prácticas y códigos trabajados en clase.

## Descripción

En este repositorio se guardan los ejercicios realizados durante las sesiones de clase, con el objetivo de practicar conceptos, mejorar la lógica de programación y tener un respaldo ordenado del avance.

## Contenido

- Ejercicios básicos.
- Prácticas vistas en clase.
- Código de ejemplo.
- Resolución de problemas.
- Notas y comentarios importantes.

## Objetivo

Practicar los temas vistos en clase y reforzar el aprendizaje mediante ejemplos de código.

## Tecnologías usadas

- JavaScript
- HTML

## Organización

Cada archivo o carpeta corresponde a un ejercicio o tema visto en clase.
